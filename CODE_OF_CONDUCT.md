# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions focused on technical merit. Harassment, personal attacks, and publishing others' private information are not tolerated.

Report unacceptable behavior privately to the maintainer, [@TING-HiuYu](https://github.com/TING-HiuYu). All reports are reviewed confidentially. The maintainer may remove comments, commits, issues, or pull requests that violate this Code of Conduct and may block repeat offenders from the repository.
